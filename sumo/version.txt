# Build on macOS (Apple silicon), headless: no sumo-gui, no GDAL.
#   brew install cmake xerces-c proj
#   git clone --depth 1 --branch v1_28_0 --recursive --shallow-submodules https://github.com/eclipse-sumo/sumo ~/sumo
#   cd ~/sumo
#   env PATH=/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin \
#     cmake -B build . -DCMAKE_BUILD_TYPE=Release -DCMAKE_IGNORE_PREFIX_PATH=/opt/anaconda3
#   env PATH=/opt/homebrew/bin:/usr/bin:/bin:/usr/sbin:/sbin nice -n 15 cmake --build build --parallel 4
# Always give --parallel a number: without one, make starts unlimited compile jobs, runs out of
# memory and freezes the computer. 4 jobs at low priority keep the computer usable.
# The PATH and CMAKE_IGNORE_PREFIX_PATH settings keep Anaconda's libraries out of the build;
# otherwise SUMO links against /opt/anaconda3/lib and breaks when Anaconda changes.
# Enabled features: FMI Proj FMT Intl.

# Add OVM (carFollowModel="OVM") after cloning and before building; run from the repository root:
#   cp sumo/ovm/MSCFModel_OVM.h sumo/ovm/MSCFModel_OVM.cpp ~/sumo/src/microsim/cfmodels/
#   git -C ~/sumo apply "$PWD/sumo/patches/register-ovm.patch"
# The patch registers the model and its vType attributes alpha (1/s), sc (m) and d (m);
# the model itself is documented at the top of sumo/ovm/MSCFModel_OVM.h. The patch changes a
# header used almost everywhere, so the next build recompiles nearly all of SUMO.

# Use it in a terminal (instead of the release installed from the SUMO website):
#   export SUMO_HOME=~/sumo
#   export PATH=~/sumo/bin:$PATH
#   sumo --version        # Eclipse SUMO sumo 1.28.0
#   python sumo/ovm/check_ovm.py   # checks OVM against theory and a reference integrator
#   pytest                # includes short OVM checks, skipped when sumo has no OVM

# Checked on 2026-10-09:
# - pytest: all 29 tests pass.
# - Ring IDM sweep (configs/ring/idm_sweep.toml): identical to SUMO 1.27.1 in every run.
# - NaSch, p = 0 (sigma = 0), 750 m ring = 100 cells of 7.5 m, vmax = 4 cells, speedDev = 0,
#   speedFactor = 1: mean speed equals the deterministic result 7.5 * min(4, (1 - rho) / rho) m/s
#   for N = 10, 20, 25, 50. Two conditions are needed: vehicles must start on cell positions
#   (N = 40 evenly spaced gives 2.5 cells and 7.5 m/s instead of 11.25), and speedDev = 0,
#   speedFactor = 1 (SUMO's default speed factor otherwise gives each car its own top speed).
# - OVM (sumo/ovm/check_ovm.py), checked on 2026-10-10 on the 1000 m ring, step 0.1 s, length 5, minGap 0, maxSpeed 25,
#   alpha 1, sc 18, d 11.6:
#   - With no perturbation every vehicle settles at V(s0), s0 = L/N - length, to 6 decimals
#     (N = 10, 20, 100, 150; N = 10 checks that leaders 95 m ahead on the next edge are found).
#   - With a 0.5 m seeded perturbation, positions and speeds agree with an independent Python
#     integrator of v' = max(0, v + dt*alpha*(V(s) - v)), x' = x + dt*v' to 5e-9 over 300 s
#     (N = 20, 30, 80, 100; 1.4e-6 for N = 50, where the jam amplifies output rounding).
#   - These parameters give collisions in the unstable range (N = 40-60, minimum gap -2.19 m);
#     the Python integrator gives the same gaps, so the overlap belongs to the model, not the code.
#   - Near the threshold, growth follows the discrete-time rate for dt = 0.1, which differs from
#     the continuous V'(s0) = alpha/2 criterion (e.g. N = 30: +0.0005/s instead of +0.0025/s).
#   - pytest: all 42 tests pass on this build.
