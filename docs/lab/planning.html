RQ3 · Planning experiment

Planning scenarios

Compare how road closures, new links and signal timing shift the network critical density and maximum flow.

Question Method Results Data

Question

  1. Do changes to the network, such as closing a road or adding a link, raise or lower the network critical density and the maximum network flow?
  2. Does adding a road always help, or can it make things worse (Braess's paradox)?

Method

GoalTest how changes to the network shift its critical density, and judge each planning scenario by its effect on the whole system.
SettingThe city district from the city-network experiment. Each scenario is first built on the 4×4 grid, then moved to the district.
ModelsIDM, run in SUMO, as in the city-network experiment.
Scenarios
  1. Baseline: the original network from the city-network experiment.
  2. Road closure: close a high-betweenness link or remove one of its lanes, as for road works.
  3. New link: add a connecting road and test for Braess's paradox.
  4. Signal timing (optional): keep the cycle length and share the green time at the bottleneck intersection by directional flow.
Control variablesScenario × network density, using the same density values as the city-network experiment.
Held fixedEverything except the changed link or intersection: the rest of the network, signals, routing rule, seed set and simulation length.
MeasurementsThe same as in the city-network experiment.
Outputs
  • D Daniel1. Macroscopic fundamental diagrams overlaid (questions 1, 2): network density on the x-axis, network flow on the y-axis, with the baseline and every scenario on the same axes. Compare where the peaks are and how high.
  • D Daniel2. Critical density and maximum flow by scenario (questions 1, 2): scenarios on the x-axis, the critical density or the maximum network flow on the y-axis, with error bars from repeated runs. If either value for the new link falls below the baseline by more than the error bars, that is Braess's paradox.
  • D Daniel3. Change in congestion (question 1): at the same density, the difference in mean speed on every link between a scenario and the baseline, drawn on the network map, showing whether jams disappear, move or grow.

The tag names who makes each figure: whoever runs an experiment makes its figures; comparisons across experiments or with real data are E's.

How the results are read

Criteria

  • Do the peaks of the macroscopic fundamental diagrams differ in position or height between scenarios?
  • Are the differences larger than the spread across repeated runs?
  • Is the critical density or maximum network flow of the new-link scenario below the baseline?
  • After the change, do congestion hot spots disappear, move or grow?

Interpretation

A scenario is judged by how it changes the critical density and the maximum network flow. A higher critical density means the network can carry more vehicles before congestion sets in. If a new road lowers the critical density or the maximum network flow, Braess's paradox has occurred.

Minimum convincing experiment

The baseline and every scenario compared at the same density values and seeds.

Common pitfall

Comparing scenarios at a single density; or showing only the scenarios that improve things.
